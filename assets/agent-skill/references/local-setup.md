# 本机连接与维护

Skill 1.5.0 配合 AI Excalidraw 桌面端 0.5.0，提供 20 个项目、文件、画布与演示元数据工具，并通过画布展示方案、结果与 Skill 流程，结合选区和聊天反馈迭代。

## 安装或更新

打开桌面端「设置 → 安装 AI 工具」，勾选本机 Codex、Claude Code、Pi、Cursor，然后点击「安装 / 更新」。界面分别显示 MCP 与 Skill 状态和安装路径。只操作勾选工具，保留其他服务器与用户配置，修改前备份；已有相同版本无需重复写入。更新后在开发工具重新加载 MCP 或重开会话以加载 Skill。首次未配置时只提醒一次，跳过后仍可从设置进入。

有当前画布项目时，状态、安装和安装指引均以该项目根目录为范围：MCP 使用 `.agents/mcp.json`（JSON `mcpServers`），Skill 使用 `.agents/skills/ai-excalidraw-desktop`。所选工具共享这份项目配置和 Skill；不会额外生成项目 `.claude`、`.cursor` 等原生配置目录，也不会写入用户全局目录或其他画布项目。没有项目时才回退到各工具原有用户级位置。内置本地聊天的运行时适配器优先读取共享配置并转换为工具原生配置或启动参数，需要时使用临时插件提供 Skill 及其原生命名空间，同时保留工具自身登录与认证。独立启动的外部 CLI 不经过内置适配器，需要按实际工具和版本使用原生配置、插件或启动参数接入；共享 `.agents/mcp.json` 并非所有外部 CLI 都能自动发现的配置，插件中的 Skill 名称也可能带命名空间。本次项目安装的写入范围仅为 `.agents`，外部接入需要写入其他位置时须另有明确授权。项目 ID 必须来自工作区已打开的项目，不能用任意目录冒充；格式错误或不安全路径会阻止安装，不会退回全局覆盖。

MCP 服务由桌面进程内置，桌面端启动即启动、退出即关闭。不依赖 Node、npm 或开发工具；开发工具是否安装或连接不影响服务运行。客户端的原生 stdio 连接器只转发请求，不提供独立服务，不自动启动桌面端；当前桌面会话结束后连接器也关闭。桌面重新打开后，在客户端重新连接 MCP。

如需手动配置，使用本机实际应用可执行文件为 command，args 为 `["--mcp-stdio"]`。macOS 通常为 `/Applications/AI Excalidraw.app/Contents/MacOS/ai-excalidraw-desktop`。安装器会使用应用当前真实路径；移动应用后在新位置运行并执行更新。

默认服务发现文件在 macOS `~/Library/Application Support/com.local.ai-excalidraw/bridge.json`，其他平台使用系统应用数据目录。服务仅监听本机回环地址，令牌每次启动更换。客户端自行读取；禁止打印令牌、在提示词中粘贴或在开发工具配置中保存令牌。`AI_EXCALIDRAW_BRIDGE_FILE` 只用于指定另一实例的连接文件。

## 未加载工具时

可使用 `node <skill-dir>/scripts/canvas.mjs status|tools|call ...` 作为备用客户端；只有此可选脚本需要 Node.js，不需要 npm 安装。它直接连接桌面端，不启动额外服务。参数放入 `--args-file` 指向的 JSON 文件。

`status` 调用 `get_workspace`，没有项目或活动画布仍可连接。等待 `initialized: true` 后才写入。`presenting: true` 时只有 `get_workspace` 可用，须用户在应用中退出演示后再继续。26 个工具中没有启动/退出演示或批注工具。

应用内本地 AI 聊天运行期间，AI 占用不会阻止该会话的 Agent 通过 MCP 操作已绑定目标画布；使用会话绑定的 `projectId`、`canvasId` 和文件路径。运行时仅允许这些 MCP 画布操作，项目导航仍锁定，不要切换项目、打开其他文件或改变绑定。演示模式仍须先退出。

连接失败先确认桌面端正在运行并显示窗口；可用系统启动方式激活已安装应用，再重试只读检查。不要为普通绘图重装客户端、关闭应用或改写配置。超时、冲突、保存失败后先读工作区和目标，不能盲目重放写入。原生文件是项目目录内的 `.excalidraw`，不要假定旧版存储目录。
