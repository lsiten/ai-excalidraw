# Desktop workspace

Preserve the existing Excalidraw editor and shared Button, Input, Dialog primitives. Project navigation is a new shell around the editor.

- Colors and fonts use existing index.css theme tokens; project surface uses card, background, muted, foreground, primary and border tokens in both themes.
- Desktop layout: project explorer defaults to 244px, drag-resizes from 220 to 480px and remembers the chosen width; leave at least 640px for the main workspace in docked mode. Narrow overlay mode leaves a 48px exposed edge. The canvas flexes beside it and the optional 320px AI inspector. The editor owns canvas scrolling; explorer, tabs and chat scroll independently.
- Explorer resizing uses an 8px invisible hit region around the existing neutral 1px divider, col-resize cursor, pointer capture and temporary selection suppression. Dragging never changes files or canvas content. Double-click resets to 244px; the focusable vertical separator exposes its current/min/max values and supports arrow keys (10px, Shift 40px) plus Home/End. Pointer cancellation rolls back. Window constraints affect the displayed width without overwriting the saved preference.
- Explorer has a project selector, root path, labelled actions, searchable file tree, and per-file action menu. Directory expansion and file selection are separate controls. Nested paths remain visible in tooltips and the canvas breadcrumb.
- Tabs use neutral hairline dividers and tonal active backgrounds. Dirty/save/conflict states use explicit text and icons. No decorative accent stripes.
- Dialog uses existing Radix accessible modal conventions, clear field labels, primary safe action, cancel, Escape and Enter. Destructive confirmation names the target and states that it moves to Trash.
- At compact desktop widths hide the inspector by default and allow explorer collapse. This is a macOS desktop workspace (minimum 800px); web/mobile retain the upstream editor.
- Save operations show progress and errors. Conflict has reload and save-copy actions. Errors stay visible until resolved. File switching waits for successful save. Incoming AI writes lock document navigation and must name the canvas ID.
- Standard Cmd-S saves; Cmd-O opens a canvas; Cmd-Shift-O opens a project. Closing the native window or quitting flushes pending documents and chat before exiting; failures leave the window open.
- No new assets, external fonts or animation libraries. Respect reduced motion for existing transient animation.

At <=1000px the canvas top toolbar uses auto/minmax/auto columns and an 8px gap, keeping the library button inside the viewport. Below 1380px desktop AI inspector opens as an overlay, so manual opening cannot shrink the editor below its usable toolbar width. Workspace operations make editor content inert; rename keeps stable tab identity and buffers edits while file persistence is paused, then drains all documents before completion. Missing/conflicted files may be closed only after explicit discard confirmation.

## Folder presentations

- Reuse Button/Input/Radix Dialog and workspace theme tokens. Preparation is a bounded list-detail dialog: 240px sortable page list owns scrolling, flexible preview owns its area, fixed header/footer. At 800px the list remains 200px and preview shrinks without horizontal page overflow.
- A file is a slide; a folder is a deck. Natural filename order is the fallback, custom order and include-subfolder setting persist in project metadata. Selected-element bounds define an optional fixed playback rectangle. Previews always render actual Excalidraw scene content, including embedded images and local fonts.
- Playback is a separate viewport overlay with native fullscreen. The slide is centered on a neutral black stage, preserving its original aspect ratio and colors. Editor and AI controls are hidden/inert; navigation returns to the previous editing position. Thumbnail rail scrolls independently.
- A compact bottom dock owns navigation, pointer, pen, highlighter, eraser, four annotation colors, undo/redo, clear-current/all, and exit. Tool selections use tonal surfaces plus aria-pressed, not decorative outlines. The dock fades with 150ms opacity after 2.5s idle, returns on pointer/keyboard input, remains visible during focus/drawing; reduced-motion removes the fade duration.
- Annotation colors: red #e03131, blue #1971c2, green #2f9e44, yellow #f2b01e; fixed pen 3px, highlighter 18px at 0.28 opacity. Ink uses normalized slide coordinates so resize keeps alignment. Each page owns an ephemeral undo history; all ink is discarded on exit. No autosave, chat, library, or editor callbacks are connected to the player.
- Errors keep setup/player controls available; a failed page render cannot silently skip content. Preparing displays page progress, empty folders have a clear empty state. Keyboard: arrows/PageUp/PageDown/Space, Home/End, Esc; P/B/H/E tools, Cmd/Ctrl-Z and Shift-Z history. All icon-only controls have labels and visible focus; destructive clear-all uses confirmation.
